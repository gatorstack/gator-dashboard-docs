# PriceList

`cost.gatorstack.dev/v1alpha1`, namespaced, только для чтения пользователями.
Это публичная витрина принятых тарифов проекта. Создание и обновление выполняет
Gator Cost; редактирование PriceList не является способом назначения цены.

| Поле | Значение |
| --- | --- |
| `spec.sourceUID`, `spec.revision` | Неизменяемая ссылка на принятый снимок тарифного плана |
| `status.title` | Название прайс-листа |
| `status.sourceName`, `status.family` | Исходный план и семейство |
| `status.scope` | `Global` — базовый, `Project` — проектный |
| `status.validFrom`, `status.validUntil` | Начало и окончание, RFC3339; окончание исключено |
| `status.currency` | RUB |
| `status.phase` | Применимость в текущем проекте |
| `status.rates[]` | Классы: `key`, `product`, `title`, `unit`, точная decimal-строка `price` |
| `status.updatedAt` | Последнее изменение витрины |

`Active` означает действующий прайс-лист. `Scheduled` ещё не начался,
`Expired` завершён, `Overridden` заменён проектным. `Conflict` означает
неоднозначность выбора; ни один конфликтующий план не показывается активным.
`Withdrawn` — отменённый будущий план. Пустое окончание означает бессрочный план.

PriceList включает только выбранные для namespace семейства и его собственные
проектные переопределения. Они заменяют базовый план целиком. История тарифов
хранится отдельно от витрины; удаление экспорта не удаляет начисления.
