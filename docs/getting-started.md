# Начало работы

Это руководство для пользователя уже установленной консоли. Администратору,
который разворачивает решение впервые, нужен раздел [Установка](operator-manual/installation.md).

## 1. Получите доступ

Получите у администратора адрес консоли и способ входа: локальную учётную запись,
внешнего провайдера или временный токен ServiceAccount. Попросите назначить
роль в нужном проекте. Учётная запись без назначения может войти, но не увидит проектов.

## 2. Войдите

Откройте адрес консоли. Введите логин и пароль либо выберите кнопку внешнего
провайдера. Для ServiceAccount раскройте соответствующий блок и вставьте токен.
Доступные способы определяются настройками вашей установки.

Подробности срока сессии и повторного входа: [Вход и выход](user-guide/login.md).

## 3. Выберите проект

После входа откроется последний доступный проект либо первый из доступных.
Для переключения используйте список под логотипом в левом меню.
Если появился экран «Нет доступных проектов», администратору нужно проверить
назначение роли; создавать новую учётную запись для этого не требуется.

## 4. Откройте сервис

Нажмите «Все сервисы», найдите продукт по названию или категории и выберите его.
В левом меню появятся страницы продукта. При переключении проекта сохраняется
выбранная страница, а данные загружаются для нового проекта.

## 5. Проверьте квоты

Перейдите в Home → Квоты. Здесь показаны использование и лимит количества
объектов проекта. Изменения появляются автоматически.

Дальше: [проекты и сервисы](user-guide/projects.md),
[работа с квотами](user-guide/quotas.md), [IAM](user-guide/iam.md).
