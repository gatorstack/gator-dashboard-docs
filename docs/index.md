# Gator Dashboard

Gator Dashboard — веб-консоль для доступа к сервисам облачной платформы.
В ней пользователь выбирает проект, открывает сервисы, просматривает ресурсы
и квоты. Администратор настраивает проекты, каталог сервисов, учётные записи
и права доступа через Kubernetes.

## Что входит в решение

**Gator Dashboard** предоставляет интерфейс, проекты, каталог и управление
доступом. Меню и страницы описываются декларативно: для нового продукта
администратор добавляет конфигурацию, а не устанавливает отдельную консоль.

**Gator Dex** предоставляет локальные учётные записи, группы и подключение
внешних провайдеров входа. Права на проекты определяет Kubernetes RBAC.

**Gator Cost с OpenMeter** учитывает потребление ресурсов и применяет тарифы.
Это дополнительный компонент с отдельным административным интерфейсом.
Установка Dashboard не устанавливает биллинг автоматически.

## Текущие возможности

- Вход через Gator Dex или токен ServiceAccount.
- Проекты с независимыми назначениями ролей.
- Каталог продуктов, формы и страницы просмотра Kubernetes-ресурсов.
- Пользователи, группы, роли и назначения доступа в IAM.
- Квоты количества объектов с автоматическим обновлением использования.
- В отдельном Gator Cost — минутный учёт, тарифные планы и расходы в RUB.

Формы с ProductResource создают и изменяют целевой CR с серверной проверкой
схемы и прав; обычные формы без binding только проверяют ввод. Готовый пример —
[IaaS](operator-manual/iaas.md).
Уведомления и операции Home пока не подключены к источникам данных.
Общий вход и пользовательское разграничение биллинга через Dashboard ещё
не подключены. Подробности и ответы на частые вопросы — в [FAQ](faq.md).
