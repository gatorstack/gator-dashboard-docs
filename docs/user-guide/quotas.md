# Квоты

Откройте Home → Квоты в нужном проекте. Таблица показывает ограничения
количества объектов: например ConfigMap, Pod, Service или PVC.

## Читать использование

Значение `2 / 20` означает, что создано два объекта при лимите двадцать.
Полоса показывает долю использования. `0` означает известное нулевое
использование; `—` — значение ещё не получено. После создания квоты Kubernetes
может заполнить использование с небольшой задержкой.

Несколько квот отображаются отдельными строками и не суммируются.
Читаемое название задаёт администратор, иначе показывается техническое имя.

## Что делать при достижении лимита

Проверьте, какие ресурсы больше не нужны, и обратитесь к владельцу проекта
или администратору для изменения лимита. Страница квот предназначена для чтения:
изменить лимит или удалить ресурс из этой таблицы нельзя.

Квота ограничивает создание объектов, а не расходы в рублях. Для стоимости
используется отдельный [учёт потребления](costs.md).

Ограничение количества CR виртуальных машин не ограничивает сумму vCPU или RAM
в их полях. Например, три CR с 2, 4 и 8 vCPU используют три объекта, но 14 vCPU.
Текущая консоль не вычисляет и не обеспечивает такую агрегатную квоту над
произвольными CR. Штатные квоты CPU/RAM Kubernetes относятся к поддерживаемым
Kubernetes-ресурсам и не становятся квотами внешних VM автоматически.

## Обновление данных

Таблица обновляется автоматически, пока страница открыта. При временном разрыве
соединения консоль восстанавливает подписку. Если вместо списка показан отказ
в доступе, нужны права на чтение и watch ResourceQuota в выбранном проекте.
