---
title: История действий
---

Откройте **Home → Операции**, чтобы увидеть действия с ресурсами проекта.
В карточке ВМ, диска или другого ресурса откройте **История**. Вкладку подключает
автор продукта через схему страницы. Удалённые объекты остаются в общем журнале
до истечения срока хранения; пересозданный объект отличается по UID.

При настроенном Kubernetes audit webhook в журнал попадают обращения через
Dashboard, kubectl/oc и другие Kubernetes API-клиенты. Автор берётся из identity,
проверенной API server. В записи видны время, действие, имя/тип/UID ресурса и итог.
Для cluster-scoped IAM проектную запись создаёт Dashboard; внешний collector не
выбирает клиентский проект для общего кластерного события по одному имени автора.

| Результат | Что означает |
| --- | --- |
| Выполняется | Запрос сохранён, но результат асинхронного действия ещё не подтверждён |
| Успешно | Получено подтверждение результата по критериям данного типа ресурса |
| Ошибка | API отклонил запрос либо ресурс сообщил актуальную ошибку согласования |
| Результат неизвестен | Не хватает подтверждения identity/поколения либо истекло ожидание |
| Заменено новым изменением | До подтверждения результата конфигурация изменилась снова |
| Успешно (API) | Старая запись подтверждает только успешный запрос API, без проверки результата провайдера |

Для простых Kubernetes-объектов без отдельного lifecycle успех означает завершённую
запись API. Для ресурсов с объявленными критериями оператор ожидает актуальный
статус поколения или наблюдаемый эффект. Старое `Ready=True` не подтверждает новую
операцию. Удаление считается завершённым после исчезновения того же UID, включая
ожидание finalizer. Не повторяйте неизвестную операцию без проверки ресурса.

Нажмите название операции. **Сведения** показывает ID операции и Audit ID,
инициатора, UID, источник, HTTP-код и основание результата. ID и имя инициатора
можно скопировать. **Изменения** сравнивает **Было** и **Стало**, **JSON** показывает
запись истории. Закройте панель крестиком или Escape. Видимые выполняющиеся
действия и открытая панель обновляются автоматически.

Значения доступны только для явно разрешённых полей, например `Размер: 20 → 40`.
Для остальных сохраняется только факт изменения; полный объект, Secret data,
пароли, токены, cloud-init и сообщения статуса с произвольными значениями в
историю не копируются. При недоступной безопасной проекции diff может отсутствовать.
У отклонённой или неизвестной операции diff показывает запрошенные изменения.

Поиск находит ID, имя/UID/GVK ресурса, действие, продукт и инициатора во всём
периоде, включая ещё не загруженные страницы. Значения изменённых полей не ищутся.
Период выбирается рядом с поиском; в **Фильтрах** задайте точное имя инициатора,
тип операции и результат, затем нажмите **Применить**. Крестик снимает одно условие.
**Обновить** загружает новые записи, **Загрузить ещё** открывает следующую страницу.
На телефоне операции представлены компактными строками, панель занимает всю ширину.

По умолчанию история хранится 30 дней в Kubernetes. Старые действия до включения
источника не восстанавливаются автоматически. Прямые cloud API и SQL-запросы не
входят в эту историю Kubernetes. Доступ даёт роль с чтением HistoryRecord в проекте;
ошибка доступа отличается от пустого журнала. При задержке доставки событие
появится после восстановления collector; администратор контролирует очередь.
