---
title: История действий
---

Откройте **Home → Операции**, чтобы увидеть действия пользователей с ресурсами
выбранного проекта. Для отдельной ВМ, диска или другого ресурса откройте его
карточку и вкладку **История**. Наличие вкладки задаёт автор продукта в схеме
страницы. Удалённые объекты остаются в общей истории до истечения срока хранения.

В записи показаны время, автор, действие, имя и тип ресурса, результат запроса.
Нажмите название операции, чтобы открыть боковую панель. Вкладка **Сведения**
показывает ID, полное имя инициатора, UID, проект, продукт и результат запроса.
Рядом с ID, UID и инициатором есть кнопки копирования. **Изменения** сравнивает
колонки **Было** и **Стало**, **JSON** показывает саму запись истории.
Закройте панель крестиком или клавишей Escape, чтобы вернуться к записи.
Для разрешённых полей видны прежнее и новое значения, например
`Размер, GiB: 20 → 40`. Для остальных — только факт изменения. Пароли, токены,
содержимое Secret, cloud-init и полное тело запроса не сохраняются.

| Результат | Значение |
| --- | --- |
| Запрос принят | Kubernetes сохранил создание/изменение либо принял запрос удаления |
| Отклонён | Kubernetes вернул ошибку; её HTTP-код доступен в подробностях |
| Исход неизвестен | Ответ не получен, сервер сообщил неопределённую ошибку либо итог не удалось сохранить |

Для отклонённого или неизвестного результата изменения в подробностях означают
запрошенные значения. Принятие запроса не означает готовность виртуальной машины,
диска или завершение удаления с finalizer: проверяйте текущий статус ресурса.
Не повторяйте неизвестную операцию, пока не проверили её фактический результат.

Поиск находит записи по ID, имени/UID/типу ресурса, действию, продукту и
инициатору во всём выбранном периоде, включая ещё не загруженные страницы.
Значения изменённых полей в поиске не участвуют. Период выбирается рядом с поиском.
В **Фильтрах** укажите точное имя инициатора, тип операции или результат и нажмите
**Применить**. Активные условия видны под панелью; крестик снимает одно условие.
Кнопка со стрелками **Обновить** загружает новые записи, **Загрузить ещё** открывает
следующую страницу. На телефоне операции показаны компактными строками;
подробности открываются на всю ширину экрана.
История отличает объекты по UID, поэтому пересоздание с прежним именем не смешивает
записи. Создание связанного ресурса видно у исходника и у результата.

По умолчанию история хранится 30 дней в Kubernetes. Срок определяет администратор.
Записи начинают появляться после включения интеграции; старые действия не
восстанавливаются задним числом. Изменения через `oc`, внешние API и контроллеры
не входят в историю действий через Dashboard. Доступ к журналу предоставляет
роль проекта с правом чтения HistoryRecord; ошибка доступа не означает пустую историю.
