# Метрики проекта

Откройте проект и выберите **Мониторинг → Метрики**. Пока это отладочный список
рядов метрик, полученных за последние пять минут: имя и все лейблы.
Каждый набор лейблов отображается отдельной строкой, даже если имя совпадает.
Колонка «Лейблы» содержит весь набор, включая `__name__`. Он включает показатели ВМ
(CPU, память, диски, сеть) и S3-бакетов (трафик, логический размер, объекты,
индивидуальные квоты). Строки появляются по мере поступления данных источников.

Поиск фильтрует имена и лейблы. **Обновить** перечитывает данные; автоматическое обновление
выполняется каждые 30 секунд. При переключении проекта список загружается заново.
Графики, значения отдельных рядов и произвольные PromQL-запросы пока не выводятся.

Каждый проект читает отдельный tenant. Вы не увидите метрики чужих ВМ/бакетов,
общие показатели Ceph OSD/PG или административный мониторинг. Для доступа нужна
роль `monitoring.viewer` или соответствующая общая роль в текущем проекте.

Если данных нет, дождитесь нескольких циклов сбора. Traffic counters могут
появиться только после операций с объектами; bucket stats обновляются с задержкой
учёта RGW. Ошибка доступа или источника показывается отдельно. Старые данные
общего административного мониторинга в проектную историю не переносятся.
