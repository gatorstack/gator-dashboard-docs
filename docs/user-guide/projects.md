# Проекты и сервисы

## Выбрать проект

Список проектов находится под логотипом. В нём отображаются только доступные
вам проекты. Имя в списке — пользовательское название, а технический namespace
можно увидеть в адресе страницы.

При смене проекта консоль сохраняет выбранный сервис и страницу. Например,
переход из квот одного проекта открывает квоты другого. Домик в хлебных крошках
возвращает на Home текущего проекта.

## Найти продукт

Откройте «Все сервисы». Каталог сгруппирован по категориям; поиск учитывает
название, категорию и описание. Выбор продукта открывает его страницы в контексте
текущего проекта. На телефоне меню открывается кнопкой в шапке.

В поставляемых пакетах категория **Infrastructure** объединяет **Compute**
(инстансы, диски, снимки, SSH-ключи; прежнее название IaaS) и **VPC** (сети и
подсети, адреса, маршрутизация и безопасность). Отдельные категории Compute и
Network для этих пакетов не используются. Оператор задаёт название сервиса в
`Product.spec.name`, а категорию — в `Product.spec.category`: одинаковое значение
объединяет продукты в одну группу без изменения приложения.

Продукт может содержать:

- информационную страницу;
- форму ввода и проверки данных;
- список Kubernetes-ресурсов и, если настроено, карточки объектов;
- раздел управления IAM.

Обычная форма без привязки к ресурсу только проверяет ввод. Настроенная форма
создания/изменения ProductResource отправляет запрос серверу. После создания
проверьте карточку и статус контроллера: запись CR не означает готовность услуги.
Для Compute доступны инстансы, диски и импорт публичных SSH-ключей. Выберите облако,
а затем доступные flavor/образ/сеть. Смена облака сбрасывает зависимый выбор.
Права и версия выбранного объекта проверяются повторно при отправке.
[Настройка IaaS](../operator-manual/iaas.md).

## Просмотреть ресурсы

На Home / Обзор раздел «Ресурсы» показывает карточки сервисов с уже созданными
объектами. Какие строки содержит карточка, определяет автор продукта.
Нажмите строку с количеством, чтобы открыть список этих объектов в текущем
проекте. Например, «4 Зоны» ведёт к четырём DNS-зонам данного проекта.

Сервис появляется, когда хотя бы один его доступный счётчик больше нуля.
Внутри такой карточки могут оставаться строки с нулём. При создании первого
или удалении последнего объекта карточки обновляются автоматически. При смене
проекта меняются и числа, и ссылки.

Продукт без настроенной карточки остаётся доступен через «Все сервисы».
Отсутствие карточки не доказывает отсутствие ресурсов: у вас также может
не быть доступа к списку. Ошибки загрузки показываются отдельно от нулей.
Сообщение «Обновление данных…» означает восстановление соединения; ранее
показанные числа в этот момент могут быть устаревшими.

В таблице доступны колонки и сортировка, настроенные администратором. Значения
обновляются автоматически. Если название объекта является ссылкой, нажмите его
для просмотра карточки. Если ссылка отсутствует, для этой страницы настроен
только список.

Выбор строк чекбоксами сам по себе не удаляет и не изменяет ресурсы. После
смены проекта таблица относится к новому namespace.

## Поделиться ссылкой

Скопируйте адрес из браузера. Ссылка сохраняет проект, сервис и страницу:

```text
/projects/team-a/products/home/pages/home-overview
```

Получатель должен иметь собственный доступ. Ссылка не передаёт вашу сессию
и не выдаёт права. Если проект удалён или недоступен, консоль покажет ошибку.
